# Factory ERP - سیستم مدیریت کارخانه نجاری و مبلمان

سیستم جامع مدیریت کارخانه شامل:
- داشبورد مدیریتی
- مدیریت محصولات نهایی
- مدیریت مواد مصرفی
- مدیریت مشتریان
- فروش و فاکتور
- مصارف انبار (BOM)
- مدیریت بدهی‌ها
- گزارشات پیشرفته

## Tech Stack
- Next.js 14
- Turso (LibSQL)
- DaisyUI + Tailwind CSS
- Deployed on Vercel
